# OpenQuant Algorithmic Trading Research

## Project Context & Disclosure

This repository represents the **public research layer** of the *OpenQuant Algorithmic Trading Research* initiative.

The **trade history CSV included in this repository contains real, historical trades** generated by a proprietary algorithmic system operating during the stated period. These trades are provided **for transparency, validation, and research reference only**.

The Python code published here **is not the exact production system used to generate those trades**. Instead, it reflects the **conceptual foundations and research inspirations** behind the proprietary algorithm, including:

* Market regime classification
* Feature engineering approaches
* Risk-aware signal generation
* Systematic, rule-based execution logic

All **proprietary execution logic, parameterization, capital allocation rules, and live trading infrastructure are intentionally excluded**.

## Purpose of This Repository

The purpose of this repository is to:

* Document the **research methodology** behind regime-based algorithmic trading
* Share **non-sensitive reference implementations** for academic and technical review
* Provide **verifiable historical outcomes** without exposing trade secrets
* Support **open research, tooling, and infrastructure development**

This repository is **not** intended to function as a live trading system.

## Use of Funds & Research Direction

The project is currently seeking **research funding** to further develop and validate:

* Advanced regime-detection models
* Improved feature representations across market conditions
* Risk modeling and drawdown control techniques
* Cross-asset generalization studies
* Independent verification and reproducibility tooling

Any funds raised are intended to support **research, validation, documentation, and infrastructure**, **not** to deploy public capital into live trading strategies.
